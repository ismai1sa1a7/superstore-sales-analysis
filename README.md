# Superstore Sales Analysis

> Practice project: exploratory analysis of the Sample Superstore dataset to build hands-on skills in Python, Pandas, and data storytelling.

## Overview

This project analyzes four years of retail sales data (2014-2017) to understand when sales peak, which products lose money, and how discounts affect profit.

## Key Findings

- **Seasonality:** September, November, and December generate **42.9%** of total sales.
- **Furniture margin:** Furniture earns only about 2.5% margin, compared to ~17% for Technology and Office Supplies.
- **Loss-making sub-categories:** Tables, Bookcases, and Supplies.
- **Discounts:** profit margin turns negative once discounts exceed 20%, and drops to -77.4% above 40%.
